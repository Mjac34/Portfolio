# Malin Jacobsson — Portfolio

Detta repo innehåller ett urval av mitt arbete inom BI, dataanalys, SQL, Power BI, maskininlärning och AI-agenter.

## Utvalda projekt

- **Larmanalys** — Analys av falska larm i vården med Python och Streamlit.
- **Northwind Agentic Playground** — AI-agenter som bygger en BI-pipeline från råa CSV-filer till en Star Schema och BI-export.
- **Nackademin_BI24** — Utbildningsbevis från Nackademin BI24, med exempel inom ETL, SQL, Power BI, datavisualisering, maskininlärning och statistisk programmering.
