## Rekommenderade höjdare att visa upp

1. **`Larmanalys/`** — tydligast. Visar end-to-end BI: data, analys, visualisering och en Streamlit-app med konkret resultat (92 % färre falska larm).
2. **`Northwind_agentic_playground/`** — modernt. Visar AI-agenter, Star Schema, och en BI-export-pipeline.
3. **`Nackademin_BI24/statistisk programmering och ML/final.malin_jacobsson.ipynb`** — ML med regression, klassificering, klustring, Random Forest, SVM och PCA.
4. **`Nackademin_BI24/PowerBI/FBC/BI24_Malin Jacobsson_FBC.pbix`** — färdig Power BI-rapport.
5. **`Nackademin_BI24/PowerBI/HKV/BI24_MalinJacobsson_HKV.pbix`** — ytterligare en färdig Power BI-rapport.
6. **`Nackademin_BI24/ETL_Assignment_2/new10/MJ Fin.pbix`** — finansiell Power BI-rapport från ETL-uppgift.
7. **`Nackademin_BI24/SQL/gruppuppgift.drawio`** — ERD/databasdesign.
8. **`Nackademin_BI24/BEV_Takes_the_Lead/presentation.docx`** — kort BEV-presentation.
