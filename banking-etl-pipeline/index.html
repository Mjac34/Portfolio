Pipeline flow

StageInput → OutputWhat happens
1. Extractdata/raw/Three messy bank CSVs: accounts, balances, transactions
2. Clean→ data/cleansed/Missing values, duplicate keys, comma numbers, scientific-notation IDs, empty columns
3. Model→ data/warehouse/Star schema: 3 fact tables + 4 dimensions
4. Report→ powerbi/Finished Power BI report on the warehouse

The same flow also exists as an SSIS package: ssis/end_to_end.dtsx.

Cleaning decisions worth noting

  • AccountNumber arrived in scientific notation in some rows — normalized back to 12-digit strings with zero-padding
  • Comma-separated numbers converted to float per column with error reporting
  • Derived columns — IsActive/LoanStatus built from CancelledDate
  • Duplicate detection before any joins, not after

Run it

pip install pandas then python pipeline.py — reads data/raw/, writes data/cleansed/ and data/warehouse/.
